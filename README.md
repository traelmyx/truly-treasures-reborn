# Truly Treasures Reborn

Treasure enchantments like Mending and Frost Walker stop showing up in villager trades and are sold by wandering traders instead, so they feel like a find again.

Port of [Truly Treasures](https://github.com/Ineffa/Truly-Treasures) by Ineffa to Minecraft 1.21.1, for NeoForge and Fabric.

## Config

`config/trulytreasures.json`. See the CurseForge page for what each setting does.

## Building

`./gradlew buildAll` builds both loaders and runs the game tests.
